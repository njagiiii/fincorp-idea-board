# Fincorp Idea Board

A real-time collaborative idea board built as an MVP with Next.js, Flask, Supabase, and Tailwind CSS.

## Tech Stack
* **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS
* **Backend:** Python, Flask
* **Database & Real-time:** Supabase (PostgreSQL, Realtime Presence, RPC Functions)

## Getting Started

### Backend
1. cd backend
2. pip install -r requirements.txt
3. python app.py

### Frontend
1. cd frontend
2. npm install
3. npm run dev
